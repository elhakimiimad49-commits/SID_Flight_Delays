## Data Organization

- `01_Raw_Data/` — Original CSV files
- `02_Cleaned_Data/` — Cleaned datasets exported from Talend
- `03_Samples/` — Small samples for testing
- `04_Data_Quality_Reports/` — Data profiling reports

## Data Processing
1. Raw data is downloaded from Kaggle.
2. Data quality is analyzed using Python and Pandas.
3. Approved cleaning rules are implemented using Talend.
4. Validated data is loaded into PostgreSQL.
5. Power BI connects to the Data Warehouse.
